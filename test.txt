1. UPDATE: azure-infra/main.tf
============================================================

Find the existing block:

resource "azurerm_storage_queue" "events" {
  count                = local.file_processing_enabled ? 1 : 0
  name                 = var.queue_name
  storage_account_name = data.azurerm_storage_account.shared.name
}

Immediately AFTER this resource and BEFORE the azurerm_service_plan resource, add:

resource "azurerm_private_endpoint" "storage_queue" {
  count = local.file_processing_enabled ? 1 : 0

  name                = "${var.queue_name}-pe"
  location            = data.azurerm_resource_group.shared.location
  resource_group_name = data.azurerm_resource_group.shared.name
  subnet_id           = var.storage_privatelink_subnet_id

  private_service_connection {
    name                           = "${var.queue_name}-psc"
    private_connection_resource_id = data.azurerm_storage_account.shared.id
    subresource_names              = ["queue"]
    is_manual_connection           = false
  }

  private_dns_zone_group {
    name = "queue-dns-zone-group"

    private_dns_zone_ids = [
      var.queue_private_dns_zone_id
    ]
  }

  tags = var.tags
}

Do not modify the existing queue resource.

The expected resource relationship is:

Existing shared Storage Account:
data.azurerm_storage_account.shared

Existing Queue:
azurerm_storage_queue.events

New Queue Private Endpoint:
azurerm_private_endpoint.storage_queue

The private endpoint must use:

private_connection_resource_id = data.azurerm_storage_account.shared.id

and:

subresource_names = ["queue"]
