Review the current Terraform implementation and modify the Azure Function architecture based on the confirmed recommendation from the Azure/network team.

BACKGROUND

We originally had:

Y1 Consumption Function
→ could not meet the required VNet/private Storage connectivity.

We then migrated to:

FC1 Flex Consumption
→ azurerm_function_app_flex_consumption
→ existing App Service delegated subnet

However, deployment now fails with:

OnlyOneServiceAssociationLinkAllowedPerSubnet

The existing delegated App Service subnet already contains:

serviceAssociationLinks/AppServiceLink

while Flex Consumption attempts to create:

serviceAssociationLinks/legionServiceLink

Therefore Flex Consumption cannot use this existing subnet.

The Azure/network team has now recommended using:

P1v4 (Premium v4)

They confirmed this is the pattern used by the CNE team and it can be scaled later if traffic increases.

GOAL

Replace the current FC1 Flex Consumption implementation with a standard Linux Azure Function App running on a P1v4 App Service Plan and integrate it with the existing confirmed App Service delegated subnet.

Target architecture:

P1v4 App Service Plan
        ↓
Linux Function App
        ↓
Existing App Service delegated subnet
        ↓
VNet integration
        ↓
Existing private Storage Account
