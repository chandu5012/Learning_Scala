Update the Terraform code in:

Repository:
vertexinc/vdf-soxcompliance-infra

Path:
azure-infra

Goal:
Fix the Azure Storage Queue private networking implementation using the working internal Vertex pattern provided by Sean Cooper.

Important architecture requirement:
The shared Private DNS zones are centrally managed.

Our team must NOT:
- create or modify the Private DNS zone itself
- create private_dns_zone_group
- join the shared Private DNS zone
- create or modify VNet links for the shared DNS zone

Our team IS allowed to:
1. Create the Queue Private Endpoint
2. Create an A record inside the existing shared Private DNS zone

The current implementation using private_dns_zone_group fails with:

LinkedAuthorizationFailed

Missing permission:
Microsoft.Network/privateDnsZones/join/action

So replace that design with:
- Private Endpoint only
- Separate DNS A record using an aliased provider for PDD Shared Resources

4. UPDATE azure-infra/main.tf
============================================================

Find the current resource:

Ensure it looks like this:

resource "azurerm_private_endpoint" "storage_queue" {
  count = local.file_processing_enabled ? 1 : 0

  name                = "${var.queue_name}-pe"
  location            = data.azurerm_resource_group.shared.location
  resource_group_name = data.azurerm_resource_group.shared.name
  subnet_id           = var.storage_privatelink_subnet_id

    name                           = "${var.queue_name}-psc"
    private_connection_resource_id = data.azurerm_storage_account.shared.id
    subresource_names              = ["queue"]
    is_manual_connection           = false
  }

  tags = var.tags

CRITICAL:
REMOVE any existing block like:

  ...

There must be NO private_dns_zone_group anywhere in the Queue Private Endpoint.

============================================================
5. ADD SEPARATE PRIVATE DNS A RECORD
============================================================

Immediately after the Queue Private Endpoint resource, add:

resource "azurerm_private_dns_a_record" "storage_queue" {
  count = local.file_processing_enabled ? 1 : 0

  provider = azurerm.shared_resources

  name                = data.azurerm_storage_account.shared.name
  zone_name           = "privatelink.queue.core.windows.net"
  resource_group_name = "pdd-sr-global-ce-private-links-east-us-2"
  ttl                 = 300

  records = [
    azurerm_private_endpoint.storage_queue[0].private_service_connection[0].private_ip_address
  ]
}

Do NOT hardcode the private IP.

The private IP must come from:

azurerm_private_endpoint.storage_queue[0].private_service_connection[0].private_ip_address

This ensures the DNS record automatically follows the Private Endpoint if its IP changes.
